# 05 编程与工程能力：把想法变成可验证的工具

> 本章解决的问题：**安全工程师的代码不需要像业务开发那样庞大，但必须可靠、可读、可复现、可审计。**

---

## 一、为什么安全工程师必须会写代码

- 你不可能靠手工点击完成 1000 台主机的排查。
- 你不可能靠别人的工具理解一个自定义协议/私有格式。
- 你不可能在报告里只说"存在漏洞"，你需要 PoC、脚本、修复补丁。
- 你不可能审计别人的代码，如果你自己没写过像样的代码。

**目标不是"成为职业程序员"，而是**：

1. 能写 500～1000 行、带测试、能交付的工具；
2. 能读懂 1 万行级别的开源项目；
3. 能用调试器定位问题，而不是靠打印和猜；
4. 能写出别人可以复现的实验代码。

## 三、Python：安全工程师的瑞士军刀

### 核心主题

- 语法、类型、控制流、函数、模块、包。
- 数据结构：list/dict/set/tuple；推导式；生成器；迭代器。
- 文件/路径/编码：`pathlib`、`open`、UTF-8、二进制。
- 异常处理、日志、命令行参数（`argparse`）。
- 标准库：`os`、`sys`、`subprocess`、`socket`、`http.client`、`json`、`re`、`hashlib`、`datetime`。
- 第三方：`requests`、`beautifulsoup4`、`scapy`、`pwntools`（按方向）。
- 测试：`pytest`、`unittest`、mock、fixture。
- 并发：`threading`、`multiprocessing`、`asyncio`（至少懂概念）。
- 打包：`pyproject.toml`、`venv`、`pip`。
- 代码质量：`ruff`、`black`、`mypy`（可选）。

### 项目阶梯

1. **文件哈希与去重工具**：遍历目录，算 SHA-256，输出重复文件。
2. **端口扫描器**：TCP connect 扫描，支持并发、超时、JSON 输出。
3. **HTTP 头检查器**：检查安全头、TLS 版本、证书到期。
4. **日志分析器**：解析 Apache/Nginx 日志，统计 Top IP、状态码、异常路径。
5. **简易漏洞扫描器**：针对本地靶场，检测目录遍历/SQLi 错误回显（只允许本地）。
6. **PCAP 分析器**：用 scapy 提取 DNS/HTTP 明文信息。
7. **Telegram/Slack 告警机器人**：把检测结果推到聊天工具（注意密钥管理）。

### 掌握标准

- 能不看教程写出 300 行带 `argparse`、日志、异常处理、测试的工具。
- 能用 `pdb`/`breakpoint()` 调试，能读 traceback 找到根因。
- 能解释 GIL、深浅拷贝、可变默认参数、编码错误。
- 能用 `venv` + `pyproject.toml` 交付，不用 `sudo pip install`。

### 资源

- Python 官方 Tutorial。
- 《Python Crash Course》。
- `fluentpython`（进阶）。
- Real Python（选读）。
- `pytest` 官方文档。

## 四、C：理解内存的唯一捷径

### 核心主题

- 类型、指针、数组、字符串、结构体、联合体、枚举。
- 内存布局：栈、堆、全局区、常量区、代码段。
- `malloc/free`、内存泄漏、悬垂指针、双重释放。
- 指针运算、函数指针、回调。
- 预处理器、宏、头文件、编译/链接。
- 标准库：`stdio`、`stdlib`、`string`、`unistd`、`sys/socket`。
- 错误处理：`errno`、返回值、`perror`。
- 调试：`gdb`、`valgrind`、ASan/UBSan。
- 安全：缓冲区溢出、整数溢出、格式化字符串、竞态。

### 项目

1. **动态数组**：实现 `vector`，支持扩容、越界检查。
2. **哈希表**：链地址法，支持插入/查找/删除。
3. **TCP 服务器**：`socket/bind/listen/accept`，多进程/`select`。
4. **简易 HTTP 服务器**：解析请求，返回静态文件。
5. **漏洞实验**：写一个故意栈溢出的程序，在虚拟机里用 gdb 观察，再修复。
6. **内存分配器**：实现一个 bump allocator，理解 `malloc` 的复杂度。

### 掌握标准

- 能解释 `char *s = "abc"` 与 `char s[] = "abc"` 的区别。
- 能用手写 Makefile 编译多文件项目。
- 能用 gdb 看栈帧、寄存器、断点、`x/` 查看内存。
- 能说出至少 5 种未定义行为，并知道它们为什么危险。

### 资源

- K&R《C 程序设计语言》。
- CS:APP 第 2～3 章。
- Beej's Guide to C Programming / Network Programming。
- 《C 陷阱与缺陷》。

## 五、Bash/PowerShell：把重复劳动变成一条命令

### Bash 核心

- 管道、重定向、`&&`/`||`、变量、引号、转义。
- `grep`、`sed`、`awk`、`cut`、`sort`、`uniq`、`xargs`、`find`。
- 条件、循环、函数、数组、`set -euo pipefail`。
- 进程管理：`ps`、`kill`、`jobs`、`nohup`、`tmux`。
- 网络：`curl`、`dig`、`nc`、`ssh`、`scp`、`rsync`。
- 安全：权限、`sudo`、日志、`cron`、`systemd`。

### PowerShell 核心

- 对象管道（不是文本管道）、`Get-*`/`Set-*`、`Where-Object`、`ForEach-Object`。
- 变量、哈希表、函数、模块、错误处理。
- Windows 事件日志、注册表、服务、计划任务、AD 模块。
- 远程管理：`Invoke-Command`、WinRM、SSH。
- 安全：执行策略、日志、AMSI、约束语言模式。

### 练习

1. 用 Bash 统计 Nginx 日志中访问量前 10 的 IP 和 404 路径。
2. 用 Bash 写一个批量 SSH 巡检脚本，输出 CSV。
3. 用 PowerShell 导出最近 7 天的登录失败事件（4625），统计源 IP。
4. 用 PowerShell 查一个 AD 用户的组成员关系（递归）。

### 资源

- 《Linux 命令行大全》。
- Bash Pitfalls（Greg's Wiki）。
- Microsoft Learn PowerShell 文档。

## 十、工程能力：让代码可交付

### 10.1 Git

- `init/clone/add/commit/status/log/diff/branch/merge/rebase`。
- `.gitignore`、`.gitattributes`、README、LICENSE。
- 提交信息：一句话说清"做了什么、为什么"。
- 不提交密钥、不提交恶意样本、不提交真实客户数据。

### 10.2 测试

- 单元测试：函数级，快、独立。
- 集成测试：跨模块，验证接口。
- 端到端测试：模拟真实流程。
- 属性测试：对输入空间生成随机用例（Hypothesis/QuickCheck）。
- 安全测试：边界、异常、权限、并发。

### 10.3 调试

- 读栈回溯、日志、退出码。
- 二分定位：注释一半代码、换输入、换环境。
- 最小复现：删到不能再删。
- 记录根因和预防措施。

### 10.4 代码审查

审查自己的代码时问：

- 输入从哪来？是否可信？
- 权限最小了吗？
- 错误处理会不会泄露信息？
- 有没有硬编码密钥？
- 依赖是否必要、是否锁定版本？
- 日志是否记录了敏感数据？
- 并发/竞态是否存在？
- 失败时是"拒绝"还是"放行"？

### 10.5 文档

每个项目必须有：

```markdown
# 项目名
## 目的
## 环境与依赖
## 安装
## 使用（含示例输入/输出）
## 设计（关键取舍）
## 安全考虑
## 测试
## 已知限制
## 参考
```

## 十一、安全编码的十条底线

1. 所有输入都不可信：长度、类型、范围、编码、来源。
2. SQL 用参数化查询，不用字符串拼接。
3. 输出按上下文编码（HTML/JS/URL/SQL/Shell）。
4. 密码用 Argon2id/scrypt/bcrypt，不用 SHA-256/MD5。
5. 密钥放 KMS/Secret Manager，不进代码、不进 Git。
6. 反序列化只接受可信格式，禁用危险 gadget。
7. 文件上传：白名单、重命名、隔离存储、不可执行。
8. 命令执行：避免 shell，用参数数组；必须时严格白名单。
9. 失败默认拒绝（fail closed），错误信息不泄露内部细节。
10. 依赖锁定版本、定期扫描、最小化。

## 十三、自测

1. Python 的 `list` 和 `tuple` 有什么区别？可变默认参数为什么危险？
2. C 的 `malloc` 后不 `free` 会怎样？`free` 后继续用呢？
3. 解释 TCP `connect` 在阻塞/非阻塞模式下的行为差异。
4. SQL 注入的根因是什么？参数化查询为什么能防？
5. 浏览器同源策略保护什么？CORS 如何放宽它？
6. Git rebase 和 merge 的区别？什么时候不该 rebase？
7. 单元测试和集成测试的边界在哪？
8. 什么是 TOCTOU？举一个文件权限相关的例子。
9. 如何安全地存储一个 API key？
10. 你的项目如果被别人接管，他能在 30 分钟内跑起来吗？
