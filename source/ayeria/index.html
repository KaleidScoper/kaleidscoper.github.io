Install

三步，装完就能写

不需要改主题目录里的任何文件。站点根目录的 _config.ayeria.yml 只写要覆盖的几项。

01

安装

在站点根目录执行，Hexo 5 及以上版本均可。

npm i hexo-theme-ayeria -S
02

写配置

新建 _config.ayeria.yml，只填想改的项；主题升级不会覆盖它。

# _config.ayeria.yml
menu:
  首页: /
  归档: /archives
search: true
darkmode: true
03

构建

本地预览用 hexo server；确认无误再交给 GitHub Actions。

hexo clean && hexo generate
Questions

几个常被问到的

需要修改主题文件吗？

不需要。站点根目录的 _config.ayeria.yml 只写要覆盖的项，主题升级不会动它。真要加样式，改站点里的 source/css/custom.styl，它加载在主题样式之后。

和原来的 Ayer 主题是什么关系？

Ayeria 是已停止更新的 Ayer 主题的活跃维护分支（之一），沿用原作者 Eric-Shen 的 SATA 许可。

还要装哪些插件？

搜索使用 hexo-generator-searchdb，字数统计使用 hexo-wordcount，其余按需开启。

深色模式会记住吗？

会！切换时写入 sessionStorage，同一标签页内刷新与跳转都保持；关闭标签页后回到系统偏好。

从一条命令开始

$ npm i hexo-theme-ayeria
