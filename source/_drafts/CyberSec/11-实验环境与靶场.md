# 11 实验环境与靶场

> 本章解决的问题：**没有安全的实验室，你学得越多，越危险。**

安全技能必须在"可以随便炸"的环境里练。但"可以随便炸"不等于"没有边界"：实验室必须与你的真实主机、家庭网络、公司网络、互联网目标隔离。

---

## 一、三条铁律

1. **隔离**：实验网络不能访问你的宿主机文件、家庭局域网、公司网络。攻击流量只留在实验网里。
2. **快照**：每次实验前快照，实验后回滚。不要把"被弄坏的环境"留到下一次。
3. **合法**：只用自己搭的靶场、官方授权的在线靶场、有书面授权的目标。不要在真实网站上"试试"。

> 违反任何一条，都可能从"学习"变成"事故"。

---

## 二、硬件与预算

### 最低配置

- CPU：4 核支持虚拟化（Intel VT-x/AMD-V）。
- 内存：16 GB（同时跑 2～3 台 VM）。
- 硬盘：512 GB SSD。
- 网络：有线优先。

### 推荐配置

- CPU：8 核/16 线程。
- 内存：32～64 GB。
- 硬盘：1 TB NVMe + 外置硬盘备份。
- 一台旧笔记本/迷你主机做专用实验机，避免污染主工作机。

### 预算参考（人民币，随市场波动）

| 项目 | 入门 | 推荐 |
|---|---|---|
| 二手工作站/迷你主机 | 1,000～2,000 | 2,500～5,000 |
| 内存升级 | 300～600 | 800～1,500 |
| SSD | 300～500 | 500～1,000 |
| 云实验 | 0～200 | 200～500/月 |
| 合计 | 1,500～3,000 | 4,000～8,000 |

> 没钱也能学：用云免费层 + 在线靶场 + 一台 16 GB 的笔记本。关键是隔离和持续练习，不是设备。

## 三、虚拟化平台

| 平台 | 优点 | 缺点 | 适合 |
|---|---|---|---|
| **Proxmox VE** | 免费、裸机、快照/克隆/网络强 | 需要一台专用机器 | 长期实验室 |
| **VMware Workstation/Fusion** | 稳定、快照、网络类型丰富 | 商业授权（个人使用政策以官网为准） | 单机实验室 |
| **VirtualBox** | 免费、跨平台 | 性能和网络配置较弱 | 入门 |
| **Hyper-V** | Windows 自带、与 WSL 集成 | 网络配置绕 | Windows 用户 |
| **UTM** | Apple Silicon 友好 | 生态较小 | Mac 用户 |
| **云主机** | 免运维、可销毁 | 有成本、网络隔离要注意 | 无本地硬件 |

**建议**：Windows 主机用 VMware/VirtualBox + WSL2；有闲置机器用 Proxmox；Mac 用 UTM/VMware Fusion。

## 四、网络设计

### 最小隔离拓扑

```
[宿主机] --(仅管理)--> [虚拟交换机]
                         ├── Kali/Parrot（攻击机）
                         ├── Ubuntu Server（目标/服务）
                         ├── Windows 10/11（目标）
                         ├── Windows Server（AD）
                         └── OPNsense（可选，防火墙/NAT）
```

### 关键设置

- 使用 **Host-only** 或 **Internal Network**，不要用 Bridged。
- 如果需要上网更新，给实验网加一个 **NAT** 出口，但用防火墙限制只允许必要的更新流量。
- 禁用共享文件夹、剪贴板共享、拖拽复制。
- 关闭宿主机与 VM 之间的 RDP/SSH 自动登录。
- 给每台 VM 固定 IP，画一张网络图。
- 用快照保存"干净基线"。

### 网络分段（进阶）

- 攻击网：Kali、靶场。
- 目标网：Web、数据库、AD。
- 管理网：Proxmox/防火墙管理。
- 恶意样本网：完全离线，仅 REMnux/FLARE VM。
- 用 OPNsense/pfSense 做路由、NAT、防火墙、IDS（Suricata）。

> 不要在同一个扁平网络里跑恶意样本和你的域控。一次横向移动就能污染整个实验室。

## 五、虚拟机清单

### 基础（阶段 1）

- **Ubuntu Server 24.04 LTS**：Linux 实验、服务、日志。
- **Kali Linux**：攻击工具（只用于授权靶场）。
- **Windows 10/11**：Windows 基础、Sysmon、事件日志。
- **Windows Server 2022/2025**：AD、DNS、组策略。

> 版本以官方当前 LTS/评估版为准；Windows 评估版有期限，到期前快照或重建。

### 靶场（阶段 2）

- **DVWA**：经典 Web 漏洞。
- **OWASP Juice Shop**：现代 Web/API。
- **WebGoat**：交互式课程。
- **Metasploitable 2/3**：综合靶机（只在内网）。
- **VulnHub**：下载 VM，本地运行。
- **HTB/TryHackMe**：在线，按 scope 使用。
- **PortSwigger Academy**：浏览器即可，首选 Web。

### 蓝队（阶段 3）

- **Security Onion**：Zeek/Suricata/Elastic。
- **Wazuh**：HIDS/SIEM。
- **Splunk Free**（每天 500 MB 限制）或 **Elastic**。
- **Atomic Red Team / Caldera**：攻击模拟。
- **Velociraptor**：端点取证。

### 恶意样本（阶段 3～4）

- **REMnux**：分析工具。
- **FLARE VM**：Windows 分析环境。
- **隔离网络**：完全离线，禁用共享。
- **样本来源**：MalwareBazaar、theZoo 等公开研究样本；不要分析来源不明的真实攻击样本。

### 云（阶段 4）

- AWS Free Tier / Azure 学生账号 / 阿里云免费试用。
- 预算告警、MFA、最小权限、实验完销毁。
- 不要在云上跑恶意样本或扫描外部目标。

## 六、搭建顺序（两周）

### 第 1 周：基础

- [ ] 安装虚拟化平台，创建 Host-only/Internal 网络。
- [ ] 安装 Ubuntu Server，配置 SSH、静态 IP、快照。
- [ ] 安装 Kali，更新工具，快照。
- [ ] 安装 Windows 10/11，启用 Sysmon（SwiftOnSecurity 配置），快照。
- [ ] 安装 Windows Server，配置 AD/DNS，创建 2 个普通用户和 1 个服务账号，快照。
- [ ] 画网络拓扑图，写 README。

### 第 2 周：靶场与日志

- [ ] Docker 部署 DVWA + Juice Shop。
- [ ] 部署 Wazuh 或 Security Onion（按内存选择）。
- [ ] 把 Windows/Linux 日志接入。
- [ ] 用 Nmap 扫描靶场，确认只看到预期端口。
- [ ] 用 Atomic Red Team 跑一个测试（如 T1059），确认能产生日志。
- [ ] 做第一次快照备份，导出 OVA/备份到外置硬盘。

## 七、云实验室（无本地硬件方案）

1. 注册云账号，开启 MFA，设置预算告警（如 20 美元/月）。
2. 创建 VPC + 两个子网（公网/私网）+ 安全组。
3. 创建一台 Linux VM（堡垒机）和一台 Web VM。
4. 用 Terraform 管理，实验完 `destroy`。
5. 用云厂商的免费安全服务（GuardDuty/Defender/云安全中心）看告警。
6. 不要开放 0.0.0.0/0 的 SSH/RDP；用 SSM/Session Manager 或堡垒机。

**成本控制**：选最小规格、用完关机、设置预算告警、定期清理快照/弹性 IP。

## 八、靶场使用规则

- **在线靶场**（HTB/THM/PortSwigger）：只攻击分配给你的目标，不扫描平台基础设施，不攻击其他玩家。
- **本地靶场**：可以随意测试，但要保证网络隔离。
- **CTF**：遵守比赛规则；不攻击比赛平台；不泄露 flag。
- **漏洞赏金**：严格按 scope；不碰第三方；不下载真实数据；发现越界立即停止并报告。
- **公司/学校**：必须有书面授权；遵守 ROE；不测试范围外系统。

## 九、常见问题

**内存不够怎么办？**
- 用轻量 Linux（Alpine/Debian minimal）。
- 一次只开 2～3 台 VM。
- 用云靶场/在线靶场替代本地。
- 加内存比换 CPU 更划算。

**VM 太慢？**
- 开启 CPU 虚拟化、安装 guest tools、用 SSD、分配足够内存。
- 关闭不必要的快照；快照会拖慢磁盘。
- 用裸机 Proxmox 而不是嵌套虚拟化。

**网络不通？**
- 检查 VM 网络模式（Host-only/NAT/Internal）。
- 检查 IP/子网/网关/DNS。
- 用 `ping`、`tcpdump`、`ss` 分层排查。
- 检查防火墙（ufw/firewalld/Windows Firewall）。

**Windows 评估版到期？**
- 快照、重建、或用合法的开发版/订阅。不要用破解版。

**恶意样本跑完宿主机异常？**
- 立即断网、回滚快照、全盘扫描；检查共享文件夹/剪贴板是否开启。
- 以后严格离线、禁用共享。

## 十、实验室检查清单

- [ ] 实验网是 Host-only/Internal，不是 Bridged。
- [ ] 共享文件夹、剪贴板、拖拽已禁用。
- [ ] 每台 VM 有干净快照。
- [ ] 有网络拓扑图和 IP 表。
- [ ] 有 README：怎么启动、怎么重置、怎么加 VM。
- [ ] 恶意样本只在离线网。
- [ ] 云账号有 MFA、预算告警、最小权限。
- [ ] 知道怎么销毁实验资源。
- [ ] 所有靶场均合法/授权。
