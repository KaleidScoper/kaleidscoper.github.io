# 网络安全学习指南：从外行到全栈式安全工程师

> **版本**：1.0
> **资料核对日期**：2026-11-01
> **适用对象**：零基础或非安全科班出身、希望在不依赖 AI 的前提下系统学习网络安全的人
> **存放位置**：`source_drafts/CyberSec/`（不在 Hexo 构建范围内，不会被发布）

> 这份指南为"AI 护栏收紧之后，仍然想靠自己的判断力做安全"而写。它不是反对 AI，而是假设你身边暂时没有 AI 可问：遇到报错、看不懂的协议、写不出的工具时，你仍然能靠文档、源码、调试器和实验往前走。

---

## 一、先说实话

这份指南不能保证你"学完就年薪百万"，也不能保证你"24 个月成为专家"。它能保证的是另一件事：

> **如果你按阶段完成这里规定的阅读、实验、项目和输出，你会拥有一个初级全栈安全工程师应有的知识结构、动手证据和继续专精的路线图；你不会再出现"不知道下一步学什么"的状态。**

"全栈式网络安全工程师"不是一个官方职业名称，也没有统一考试。这份指南把它定义为一个**T 型能力结构**：

- **横向**：对基础学科、系统、网络、密码学、Web、二进制、蓝队、云安全、治理合规都有 L2～L3 的理解，能和任何方向的安全工程师对话、能独立完成标准任务。
- **纵向**：在其中一个方向达到 L4，能设计、排障、迁移到新场景，并能写出让别人复现的报告。
- **底座**：数学、计算机科学、编程、英语、写作、法律伦理。这些决定你能走多远，而不是起跑多快。

这里的"全栈"是**广度的目标**，不是"每个领域都成为专家"。一个人不可能同时是内核漏洞研究员、AD 红队专家、云安全架构师和合规负责人；但一个合格的全栈安全工程师应该知道这些领域在解决什么问题、边界在哪里、什么时候该找谁。

## 三、24 个月路线图速览

基准节奏：**每周 18 小时**，约 24 个月，总投入约 1,750 小时。

| 阶段 | 时间 | 核心任务 | 出口证据 |
|---|---|---|---|
| 0 校准 | 第 0～2 周 | 搭实验环境、做基线测试、写学习契约 | 可用的隔离实验室 + 基线报告 |
| 1 地基 | 第 1～4 月 | 数学 I、CS 基础、Python/C、Linux、TCP/IP | 网络工具 + 抓包报告 + 数学题集 |
| 2 核心 | 第 5～9 月 | 密码学、Web 安全、系统安全、网络防御 | 50 个 Web 靶场 + 加固基线 |
| 3 专精 | 第 10～14 月 | 选主攻方向（Web/二进制/蓝队/云），同时补广度 | 3 份可复现的实战报告 |
| 4 工程 | 第 15～19 月 | 云原生、CI/CD、检测工程、代码审计 | 安全流水线 + K8s 加固 + 检测规则库 |
| 5 综合 | 第 20～24 月 | Capstone 红蓝对抗、作品集、求职 | Capstone 报告 + 作品集 + 面试 |
| 6 长期 | 第 25 月起 | 专精、研究、开源、社区、认证 | 会议演讲/开源项目/深度研究 |

**依赖关系（不要跳级）**：

```
数学/CS 基础
   ├─> 编程与系统 ──> 密码学/Web/网络防御 ──> 专精方向（Web/二进制/蓝队/云）
   └─> 网络协议   ──> 系统/AD/日志      ──> 工程化（云原生/供应链/检测/治理）
                                              └─> Capstone + 求职
```

> 图中的箭头是"最低依赖"，不是"学完才能碰下一个"。可以并行，但不要在没有 C/内存基础时直接刷 pwn，也不要在没学概率时调检测规则。

**三种节奏**：

| 每周投入 | 到"可就业初级"约需 | 适合情况 |
|---|---|---|
| 12 小时 | 36 个月 | 有全职工作/学业，只能晚上和周末 |
| 18 小时 | 24 个月 | 基准节奏，每天 2～3 小时 + 周末半天 |
| 30 小时 | 14～16 个月 | 脱产、间隔年、实习前集中冲刺 |

> 时间估算的假设是：你有高中以上的数学基础、能读英文技术文档、有一台能跑虚拟机的电脑。若这些不成立，先补英语和计算机操作，时间会延长 20%～50%。

## 四、开始前必须接受的五条铁律

1. **只在自己拥有或明确授权的系统上动手。** 未经授权的扫描、爆破、漏洞利用，在任何国家都可能构成违法，中国《网络安全法》《数据安全法》《个人信息保护法》《刑法》相关条款都不是摆设。实验一律放在隔离虚拟机或合法靶场。
2. **第一遍只读一手材料。** 官方文档、RFC、标准原文、源码、`man` 手册、论文。二手总结和短视频只能在建立地图后用来查漏，不能替代第一遍。
3. **每学一个概念，必须留下一个作品。** 一段能跑的代码、一份抓包分析、一篇能让他人复现的实验报告、一条能触发告警的检测规则。没有产出的"学习"不算完成。
4. **不收集工具，只解决问题。** 工具是答案的一部分，不是能力本身。先能手工解释原理，再允许自己用自动化工具。
5. **每周至少写一次、教一次。** 写作和讲解是检验理解的最低成本方式；只输入不输出，会在第 6 个月出现"看过但不会"的幻觉。

## 五、第一周做什么

按顺序完成，不要跳：

- [ ] 读完本文件、[01-能力模型与路线图](01-能力模型与路线图.md)、[02-无AI学习法](02-无AI学习法.md)。
- [ ] 做 [14-自测、里程碑与FAQ](14-自测、里程碑与FAQ.md) 里的基线测试，把分数记下来（不追求高分，只为 6 个月后对比）。
- [ ] 按 [11-实验环境与靶场](11-实验环境与靶场.md) 搭一个**隔离**虚拟机：Ubuntu Server + Kali + Windows（如条件允许），确认虚拟网络不能访问你的宿主机文件。
- [ ] 建一个 Git 仓库 `cybersec-journey`，目录：`notes/`、`labs/`、`writeups/`、`projects/`、`scripts/`。
- [ ] 写一份学习契约：目标、每周时间、不可妥协的底线、退出条件（见 01 章模板）。
- [ ] 选一个固定学习时段，写进日历，连续执行 7 天。
- [ ] 建立 Anki 牌组：`网络端口`、`HTTP 状态码`、`Linux 命令`、`密码学概念`，每张卡只放一个事实。

## 六、这份指南的边界

- **不是法律意见。** 涉及中国法律、等保、数据出境的段落只做学习索引；具体项目请咨询律师或合规负责人。
- **不是就业保证。** 就业取决于地区、学历、项目质量、实习机会、面试表现和市场周期。指南能提高概率，不能承诺结果。
- **不是知识百科。** 每章给的是"学什么、按什么顺序、做到什么程度、用什么材料、如何自测"，具体知识需要你回到一手材料里学。
- **会过时。** 标准、认证、工具版本变化很快。文中标注了核对日期；凡涉及版本、价格、考试结构，执行前以官方网站为准。
- **不提供攻击配方。** 所有攻防内容都以理解原理、构建防御、合法实验为目标；不提供针对真实目标的入侵步骤、武器化代码或规避执法的方法。
