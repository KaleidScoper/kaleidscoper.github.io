# 03 数学基础：安全工程师的"内功"

> 本章解决的问题：**不学数学，你也能用工具；但学不好数学，你很难判断工具为什么错、什么时候会失效。**

---

## 一、先破除三个误解

**误解一：安全是"手艺活"，数学没用。**
做渗透测试确实可以不会微积分，但以下问题都绕不开数学：

- 这个随机数生成器为什么可预测？（概率、熵）
- 这个哈希为什么不能防碰撞？（生日悖论）
- 这个 RSA 实现为什么能被恢复明文？（数论、填充）
- 这条检测规则的误报率到底多高？（贝叶斯、假设检验）
- 这个漏洞利用为什么"有时候成功有时候失败"？（概率、堆布局）
- 这个静态分析工具为什么不可能证明"没有漏洞"？（可计算性）

**误解二：要把数学系课程学完才能做安全。**
不需要。你需要的是"**能读懂定义、能手推关键结论、能用代码验证、知道在安全哪里用**"。形式化证明的深度可以低于数学系，但概念的准确性不能打折。

**误解三：数学要"先学完，再学安全"。**
错。数学应该**边用边补、螺旋上升**：先学离散和概率，支撑协议与风险；学到密码学时补数论；学到二进制时补信息论；学到 AI 安全时补优化。每学一个数学概念，立刻找一个安全中的用途，否则很快忘。

---

## 二、学习原则

1. **定义优先**：每个概念先写清楚定义、输入、输出、前提，再谈应用。
2. **手推一遍**：关键定理至少自己推一次，推不出来就看懂后合上书重写。
3. **代码验证**：能用 20 行 Python 验证的，不要只背结论。
4. **反例思维**：每学一个定理，问"如果去掉这个条件，会有什么反例"。
5. **安全映射**：每个模块结束，写一页"这些数学在安全中哪里出现、误用会怎样"。
6. **不追求一次懂**：第一遍懂 60% 就够，后面在密码学、协议、检测中反复回来。

## 三、七个模块

总学时约 **215 小时**。不必一次学完，按路线图分散到 12～24 个月。

### M1 离散数学（40 小时）

**核心内容**

- 命题逻辑、谓词逻辑、量词、真值表、逻辑等价。
- 证明方法：直接证明、逆否、反证、数学归纳法、强归纳、结构归纳。
- 集合、关系、函数、等价关系、偏序、基数、可数/不可数。
- 组合计数：排列、组合、二项式、鸽巢原理、容斥原理、递推关系。
- 图论：路径、连通性、树、二分图、平面图、着色、网络流、最短路。
- 布尔代数、有限状态机、正则语言、自动机初步。
- 数论初步：整除、gcd、模运算、同余、中国剩余定理。

**安全中的用途**

| 概念 | 安全场景 |
|---|---|
| 关系与传递闭包 | RBAC 角色继承、AD 权限传递、攻击图可达性 |
| 图论 | 网络分段、横向移动路径、最小割（隔离点） |
| 组合计数 | 暴力破解空间、密码策略强度、密钥空间 |
| 鸽巢原理 | 哈希碰撞必然性、端口扫描、唯一 ID 冲突 |
| 布尔逻辑 | 防火墙规则、访问控制策略、漏洞条件组合 |
| 自动机 | 协议状态机、正则表达式拒绝服务（ReDoS）、输入校验 |
| 归纳法 | 证明递归算法/协议不变式、循环不变量 |

**练习**

1. 证明一个含 $n$ 个元素的集合有 $2^n$ 个子集。
2. 把 RBAC 的"用户-角色-权限"建模为关系，写出判断用户是否有某权限的表达式。
3. 给定一张攻击图，求从入口到域控的最短路径和最小割。
4. 计算 8 位密码（大小写字母+数字）的搜索空间；若每秒尝试 $10^{10}$ 次，穷举需要多久？
5. 用归纳法证明：二叉树的叶子数 = 度为 2 的节点数 + 1。

**资源**

- MIT 6.042J《Mathematics for Computer Science》（OCW，免费教材）。
- Richard Hammack《Book of Proof》（免费）。
- Rosen《Discrete Mathematics and Its Applications》（选读，例子多）。
- 中文：《离散数学及其应用》译本。

### M2 线性代数（30 小时）

**核心内容**

- 向量、矩阵、线性组合、张成空间、线性无关、基、维数。
- 线性方程组、高斯消元、秩、逆矩阵、行列式。
- 线性映射、核与像、特征值/特征向量、对角化。
- 内积、正交、投影、Gram-Schmidt、SVD。
- 有限域上的线性代数：$\mathrm{GF}(2)$、$\mathrm{GF}(2^8)$、线性码。

**安全中的用途**

| 概念 | 安全场景 |
|---|---|
| $\mathrm{GF}(2^8)$ 运算 | AES 的 MixColumns、S-box 构造 |
| 矩阵乘法/逆 | Hill 密码、线性码、纠错 |
| 秩与线性相关 | 线性密码分析、CRC、纠错码能力 |
| 特征值/SVD | 机器学习安全、异常检测、信号分析 |
| 有限域线性代数 | Reed-Solomon、Shamir 秘密共享、MPC |
| 格（lattice）基础 | LLL、格密码（PQC）、部分 CTF 题 |

**练习**

1. 实现 $\mathrm{GF}(2^8)$ 的加法和乘法（模不可约多项式 $x^8+x^4+x^3+x+1$）。
2. 实现 AES 的 MixColumns 一轮，验证测试向量。
3. 用 Hill 密码加密一段文字，再尝试已知明文攻击。
4. 计算一个线性码的生成矩阵和校验矩阵的秩，判断能检测/纠正几位错误。
5. 用 SVD 做一次简单的图像压缩，理解"低秩近似"。

**资源**

- MIT 18.06《Linear Algebra》（Gilbert Strang，OCW）。
- 3Blue1Brown《Essence of Linear Algebra》（建立直觉）。
- Axler《Linear Algebra Done Right》（理论深，选读）。
- 中文：《线性代数应该这样学》。

### M3 概率论与统计（40 小时）

**核心内容**

- 样本空间、概率公理、条件概率、独立性、全概率公式、贝叶斯公式。
- 随机变量、离散/连续分布：均匀、二项、几何、泊松、指数、正态。
- 期望、方差、协方差、相关系数、条件期望。
- 大数定律、中心极限定理。
- 参数估计、置信区间、假设检验、卡方检验、p 值。
- 线性回归、逻辑回归初步。
- 熵、互信息（与 M5 衔接）。

**安全中的用途**

| 概念 | 安全场景 |
|---|---|
| 贝叶斯公式 | IDS 告警的后验概率、钓鱼邮件判定、取证更新 |
| 基础比率谬误 | 为什么"99% 准确"的检测器仍然大量误报 |
| 生日悖论 | 哈希碰撞、随机 ID、会话令牌 |
| 分布与尾概率 | 异常检测、DDoS 基线、密码破解时间 |
| 假设检验 | A/B 测试检测规则、比较安全策略效果 |
| 置信区间 | 漏洞扫描覆盖率、风险估计的不确定性 |
| 回归 | 风险评分、威胁情报关联、用户行为分析 |
| 熵 | 密码强度、随机性质量、隐蔽信道容量 |

**练习**

1. 某 IDS 的 TP 率 90%，FP 率 1%，攻击先验概率 0.1%。求告警为真时的后验概率。感受"基础比率"的威力。
2. 一个 32 位哈希，随机取多少个值会有 50% 概率碰撞？用生日悖论公式估算。
3. 密码策略"至少 8 位，含大小写和数字"，估算熵；若攻击者每秒 $10^{10}$ 次，离线破解需要多久？
4. 设计一个检测规则，画出 FP/FN 随阈值变化的曲线，说明你如何选阈值。
5. 用正态分布模拟正常登录时间，找出异常阈值，并计算误报率。

**资源**

- Harvard Stat 110（Joe Blitzstein，YouTube + 教材）。
- Blitzstein & Hwang《Introduction to Probability》。
- MIT 6.041《Probabilistic Systems Analysis》。
- 中文：《概率论与数理统计》（浙大版）作为应试补充。

### M4 数论与抽象代数（40 小时）

**核心内容**

- 整除、素数、算术基本定理、gcd、欧几里得算法、扩展欧几里得、贝祖等式。
- 同余、模逆、中国剩余定理、欧拉函数、费马小定理、欧拉定理。
- 群、子群、陪集、拉格朗日定理、循环群、生成元、离散对数。
- 环、理想、域、有限域、多项式环。
- 椭圆曲线：群律、点加、标量乘、ECDH/ECDSA 基础。
- 格与 LLL 初步（为 PQC 和 CTF 做准备）。

**安全中的用途**

| 概念 | 安全场景 |
|---|---|
| 模运算/模逆 | RSA、DH、ElGamal、DSA |
| 中国剩余定理 | RSA 加速、故障攻击、秘密共享 |
| 欧拉定理/费马小定理 | RSA 正确性、素数测试 |
| 群/离散对数 | DH、DSA、ECDSA、ElGamal |
| 有限域 | AES、Reed-Solomon、Shamir |
| 椭圆曲线 | ECDH、ECDSA、EdDSA、TLS 1.3 |
| 格/LLL | 格密码、部分 CTF、密码分析 |

**练习**

1. 取 $p=61,q=53,e=17$，计算 $n,\varphi(n),d$，加密 $m=65$ 再解密。
2. 用扩展欧几里得求 $17^{-1} \bmod 3120$。
3. 用 CRT 求解一组同余方程。
4. 实现 Diffie-Hellman 玩具版本，验证共享密钥一致。
5. 在小素数曲线上实现椭圆曲线点加和标量乘。
6. 用 LLL 解一个简单的背包/格问题（可选）。

**资源**

- Victor Shoup《A Computational Introduction to Number Theory and Algebra》（免费）。
- Katz & Lindell《Introduction to Modern Cryptography》第 1～5 章（数学与密码学衔接）。
- Boneh《Cryptography I》（Coursera）。
- 中文：《数论概论》《密码学数学基础》。

### M5 信息论（20 小时）

**核心内容**

- 熵、联合熵、条件熵、互信息、KL 散度。
- 信源编码：Huffman、算术编码；信道容量；纠错码初步。
- 最小熵、伪随机性、计算不可区分性（概念级）。
- 压缩与加密的区别：压缩不提供保密性。

**安全中的用途**

| 概念 | 安全场景 |
|---|---|
| 熵/最小熵 | 密码强度、密钥生成、随机数质量 |
| 互信息 | 侧信道分析、隐蔽信道、特征选择 |
| 压缩 | CRIME/BREACH 攻击、流量分析 |
| 纠错码 | 容错、隐写、PQC 中的编码 |
| 伪随机性 | PRNG 设计、流密码、模拟器 |

**练习**

1. 估算英文文本的熵（每字符约多少比特），解释为什么压缩能省空间但不能加密。
2. 给定一个密码策略，计算其熵，并与"至少 12 位随机字符"比较。
3. 用 LSB 隐写藏一段文字，再写脚本检测；计算嵌入容量与可检测性。
4. 解释 CRIME/BREACH 攻击为什么依赖压缩率与秘密的相关性。

**资源**

- MacKay《Information Theory, Inference, and Learning Algorithms》（免费）。
- Cover & Thomas《Elements of Information Theory》（选读）。

---

### M6 微积分与优化（25 小时，建议但不强求）

**核心内容**

- 极限、导数、链式法则、偏导、梯度、Jacobian、Hessian。
- 凸集、凸函数、拉格朗日乘子、对偶。
- 梯度下降、随机梯度下降、正则化、过拟合。
- 线性规划、整数规划初步。

**安全中的用途**

| 概念 | 安全场景 |
|---|---|
| 梯度 | 对抗样本、模型窃取、投毒攻击 |
| 凸优化 | 资源分配、防御预算、检测阈值优化 |
| 正则化 | 防止检测模型过拟合、提高泛化 |
| 线性规划 | 网络隔离、访问控制最小化、覆盖率优化 |

**练习**

1. 手算一个简单函数的梯度，写 20 行梯度下降。
2. 用逻辑回归做一个钓鱼 URL 分类器，观察过拟合与正则化。
3. 用线性规划给一个网络选择最少的隔离点，使攻击路径被切断。

**资源**

- MIT 18.01/18.02（微积分）、18.06（线代）。
- Deisenroth et al.《Mathematics for Machine Learning》（免费）。
- Boyd《Convex Optimization》（选读）。

### M7 计算理论与复杂性（20 小时）

**核心内容**

- 有限自动机、正则语言、上下文无关文法。
- 图灵机、可判定性、停机问题、归约。
- P、NP、NP-complete、PSPACE、随机化算法。
- 单向函数、计算不可区分性（概念级）。

**安全中的用途**

| 概念 | 安全场景 |
|---|---|
| 可判定性 | 静态分析不可能"证明所有程序无漏洞" |
| 停机问题 | 恶意代码检测的极限、沙箱逃逸 |
| NP-complete | 密码学假设、组合优化、漏洞利用规划 |
| 自动机 | 协议状态机、正则表达式、输入过滤 |
| 复杂性 | 暴力破解可行性、参数选择、DoS 成本 |

**练习**

1. 画出 TCP 状态机的简化自动机，找出异常转移。
2. 用对角化论证解释停机问题不可判定。
3. 解释为什么"没有通用算法能判定任意程序是否有内存漏洞"。
4. 用正则表达式写一个邮箱校验，再构造一个 ReDoS 输入，解释复杂度。

**资源**

- Sipser《Introduction to the Theory of Computation》。
- MIT 18.404J《Theory of Computing》。

## 五、自测：你能过关吗

不看资料，尝试回答；能写出关键步骤才算过。

1. 用归纳法证明：$n$ 个元素的集合有 $2^n$ 个子集。
2. 解释等价关系与偏序的区别，各举一个安全中的例子。
3. 求 $\gcd(252,198)$，并表为贝祖等式。
4. 求 $17^{-1} \bmod 3120$。
5. 写出 RSA 的密钥生成、加密、解密，并解释为什么正确。
6. 解释 Diffie-Hellman 为什么在窃听下仍能协商密钥，它的困难假设是什么。
7. 某检测器 TP 率 95%、FP 率 2%，攻击先验 0.5%，求告警为真的概率。
8. 解释生日悖论，并估算 64 位哈希在多少条记录时碰撞概率达到 1%。
9. 计算一个 10 位随机密码（95 个可打印字符）的熵；若每秒 $10^{12}$ 次，穷举时间是多少？
10. 解释为什么"通用静态分析工具无法证明任意程序没有漏洞"。
11. 用 $\mathrm{GF}(2^8)$ 计算 $0x57 \cdot 0x83$（AES 的经典例子）。
12. 解释压缩与加密的区别，以及 CRIME/BREACH 的攻击条件。

## 七、给"数学焦虑者"的话

- 你不需要在 3 个月内补完四年数学。你需要的是**在用到的时候能学进去**。
- 看不懂证明时，先看例子，再回头看定义，最后抄一遍证明并合上书重写。
- 每天 30～45 分钟，连续 6 个月，比周末突击 8 小时有效得多。
- 把"我不会数学"换成"我还没学到这个工具"。前者是身份判断，后者是进度描述。
- 数学的回报是复利的：前 3 个月很慢，第 6 个月开始，你会发现密码学、协议、检测、二进制都变得"可解释"了。
