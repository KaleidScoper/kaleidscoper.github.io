# 04 计算机科学基础：从晶体管到 HTTP

> 本章解决的问题：**安全漏洞几乎都藏在"抽象泄漏"的地方。你越知道底层怎么工作，越能看见别人看不见的缝。**

---

## 一、学习地图

一个安全工程师需要的计算机科学基础，不是"把 CS 本科四年重读一遍"，而是下面这条主线：

```
数字/逻辑 → CPU/内存 → 操作系统 → 网络 → 应用/数据 → 分布式系统
                ↘ 编译/链接/加载 ↗
```

每个层次都要能回答三个问题：

1. 这一层向上提供了什么抽象？
2. 这个抽象在什么情况下会泄漏？
3. 攻击者会从哪里利用这个泄漏？防御者在哪里布点？

## 二、计算机组成与体系结构（50 小时）

### 核心内容

- 二进制、十六进制、补码、位运算、字节序（大端/小端）。
- 整数溢出、符号扩展、浮点数 IEEE 754、精度丢失。
- CPU：寄存器、指令周期、流水线、乱序执行、分支预测。
- 内存层次：寄存器 → L1/L2/L3 → 主存 → 磁盘；缓存行、局部性。
- 虚拟内存：页表、MMU、TLB、缺页、mmap。
- 中断、异常、系统调用、DMA、设备 I/O。
- 多核、缓存一致性、内存屏障、原子指令。

### 安全中的用途

| 概念 | 安全场景 |
|---|---|
| 补码/整数溢出 | 缓冲区大小计算错误、越界、提权 |
| 字节序 | 网络协议解析、二进制漏洞利用、取证 |
| 浮点精度 | 金额计算、签名验证、共识漏洞 |
| 缓存 | 侧信道（Flush+Reload、Prime+Probe） |
| 虚拟内存 | ASLR、页权限（NX）、内存取证 |
| 原子指令 | 竞态条件、TOCTOU、锁绕过 |
| 系统调用 | 沙箱、seccomp、容器逃逸 |

### 练习

1. 用 C 写一个程序，演示有符号整数溢出和无符号回绕，打印结果并解释。
2. 用 `objdump -d` 看一个简单函数的汇编，指出参数放在哪些寄存器。
3. 用 `/proc/<pid>/maps` 看一个进程的虚拟内存布局，标出栈、堆、代码段、共享库。
4. 写一个多线程计数器，不用锁，观察丢失更新；再用原子操作修复。

### 资源

- CS:APP《深入理解计算机系统》第 2、3、6、9 章。
- MIT 6.004《Computation Structures》。
- 《程序员的自我修养：链接、装载与库》。

## 三、操作系统（80 小时）

### 核心内容

- 进程、线程、上下文切换、进程状态、fork/exec/wait。
- 调度：FCFS、SJF、轮转、多级反馈队列、CFS。
- 同步：互斥锁、信号量、条件变量、读写锁、自旋锁。
- 死锁：互斥、持有并等待、不可抢占、循环等待；预防/避免/检测。
- 内存管理：分页、分段、页表、换页、内存映射、OOM。
- 文件系统：inode、目录、权限、硬链接/软链接、日志、挂载。
- 权限模型：UID/GID、setuid/setgid、capabilities、ACL、SELinux/AppArmor。
- 系统调用、中断、信号、管道、IPC、socket。
- 命名空间、cgroups、容器原理。
- 启动流程：BIOS/UEFI → bootloader → kernel → init/systemd → 用户空间。

### 安全中的用途

| 概念 | 安全场景 |
|---|---|
| 进程/线程 | 提权、注入、竞态、服务隔离 |
| 权限模型 | setuid 提权、sudo 配置错误、容器逃逸 |
| 文件系统 | 符号链接攻击、权限位、SUID 排查 |
| 命名空间/cgroups | 容器隔离、资源限制、逃逸面 |
| 信号/管道 | 竞争条件、命令注入、日志注入 |
| 启动流程 | bootkit、secure boot、持久化 |
| 内核模块 | rootkit、驱动漏洞、eBPF |

### 练习

1. 用 `strace` 跟踪 `ls` 的系统调用，列出它打开的文件和调用的 syscall。
2. 写一个 setuid 程序，故意留下命令注入，然后在虚拟机里提权，再修复。
3. 用 `ps`、`/proc`、`lsof`、`ss` 手工排查一个"端口被占用"的问题。
4. 用 `unshare`/`nsenter` 观察命名空间隔离；用 `cgcreate` 限制内存。
5. 读 `/etc/passwd`、`/etc/shadow`、`/etc/sudoers`，解释每一列的权限含义。

### 资源

- OSTEP《Operating Systems: Three Easy Pieces》（免费）。
- MIT 6.S081（xv6 实验）。
- 《Linux 内核设计与实现》（选读）。
- 《Windows Internals》第 1 卷（Windows 方向必读）。

## 四、网络（80 小时）

### 核心内容

- 分层模型：OSI 七层 vs TCP/IP 四层；封装/解封装。
- 链路层：以太网、MAC、ARP、VLAN、STP。
- 网络层：IPv4/IPv6、子网、CIDR、路由、NAT、ICMP、分片。
- 传输层：TCP 三次握手/四次挥手、状态机、重传、拥塞控制、UDP、QUIC。
- 应用层：DNS、HTTP/1.1、HTTP/2、HTTP/3、TLS、SMTP、SSH、DHCP、NTP。
- 中间设备：交换机、路由器、防火墙、负载均衡、代理、CDN、WAF。
- 网络诊断：`ping`、`traceroute`、`dig`、`curl`、`tcpdump`、Wireshark、`ss`。
- 路由协议：OSPF、BGP 基础；BGP 劫持/泄露。
- 无线：Wi-Fi 认证、WPA2/WPA3、蓝牙基础。

### 安全中的用途

| 概念 | 安全场景 |
|---|---|
| ARP | ARP 欺骗、中间人、内网嗅探 |
| IP 分片 | 分片重叠、IDS 规避、DoS |
| TCP 状态机 | SYN flood、扫描、连接耗尽、会话劫持 |
| DNS | 缓存投毒、DNS 隧道、域前置、DGA |
| HTTP | 请求走私、缓存投毒、Host 头攻击 |
| TLS | 降级、证书校验、SNI 泄露、中间人 |
| BGP | 路由劫持、流量牵引、前缀泄露 |
| NAT/代理 | 溯源困难、绕过边界、隧道 |

### 练习

1. 用 Wireshark 抓一次 `curl https://example.com`，标出 DNS、TCP 握手、TLS ClientHello/ServerHello、HTTP 请求/响应。
2. 用 `tcpdump` 抓一次 ping，解释 ICMP 报文结构。
3. 用 `dig +trace` 跟踪一次域名解析，画出递归/迭代查询路径。
4. 用 `openssl s_client -connect` 看证书链、TLS 版本、密码套件。
5. 用 `ss -tanp` 和 `iptables`/`nft` 观察并限制一个端口的连接。
6. 在隔离实验网里用 `arpspoof` 做一次 ARP 欺骗，观察流量变化，再写防御规则。

### 资源

- 《TCP/IP 详解 卷 1：协议》（经典，选读重点章）。
- 《计算机网络：自顶向下方法》。
- Stanford CS144《Introduction to Computer Networking》。
- RFC 9110（HTTP）、RFC 8446（TLS 1.3）、RFC 1035（DNS）。

## 五、数据结构与算法（50 小时）

### 核心内容

- 数组、链表、栈、队列、哈希表、树、堆、图。
- 排序、二分、递归、分治、贪心、动态规划、回溯。
- 复杂度：时间/空间、最坏/平均、摊还分析。
- 字符串匹配、正则表达式、解析。
- 图算法：BFS/DFS、最短路、最小生成树、拓扑排序、最大流。

### 安全中的用途

| 概念 | 安全场景 |
|---|---|
| 哈希表 | 去重、缓存、哈希碰撞 DoS |
| 树/图 | 攻击图、依赖图、调用图、权限图 |
| BFS/DFS | 漏洞可达性、横向移动路径 |
| 动态规划 | 漏洞利用规划、密码分析、模糊测试 |
| 正则 | 输入校验、WAF 规则、ReDoS |
| 复杂度 | 暴力破解可行性、DoS 成本、算法绕过 |

### 练习

1. 用 Python 实现哈希表，处理冲突；构造一个哈希碰撞 DoS 输入。
2. 用 BFS 在 AD 权限图中找从普通用户到域管的路径。
3. 用正则写一个 URL 校验器，构造 ReDoS 输入，再用超时/DFA 修复。
4. 用动态规划解一个简单的“最小割”或“背包”问题，解释与安全资源分配的关系。

### 资源

## 六、数据库（30 小时）

### 核心内容

- 关系模型、表、主键/外键、范式。
- SQL：SELECT、JOIN、GROUP BY、子查询、窗口函数、事务。
- 索引、执行计划、慢查询。
- 事务 ACID、隔离级别、MVCC、锁。
- NoSQL：键值、文档、图、列族；CAP 取舍。
- 权限、备份、加密、审计。

### 安全中的用途

| 概念 | 安全场景 |
|---|---|
| SQL | 注入、盲注、堆叠注入、NoSQL 注入 |
| 权限 | 数据库账号最小权限、横向移动 |
| 事务/锁 | 竞态、死锁 DoS、业务逻辑漏洞 |

| 备份 | 勒索软件、数据恢复、取证 |
| 审计 | 合规、入侵检测、数据泄露溯源 |

### 练习

1. 建一个含用户/订单/日志的库，写 10 条查询，包括 JOIN 和窗口函数。
2. 在一个故意有漏洞的 Web 应用里做 SQL 注入（本地靶场），再用参数化查询修复。
3. 用 `EXPLAIN` 看一条慢查询，加索引并比较。
4. 模拟两个事务的竞态，观察隔离级别的影响。

## 八、编译、链接与加载（30 小时）

### 核心内容

- 源代码 → 预处理 → 编译 → 汇编 → 链接 → 加载 → 执行。
- 目标文件格式：ELF（Linux）、PE（Windows）；节、段、符号表、重定位。
- 静态链接 vs 动态链接；PLT/GOT；延迟绑定。
- 调用约定：System V AMD64、Windows x64；栈帧、参数传递、返回值。
- 库搜索路径、RPATH/RUNPATH、LD_PRELOAD、DLL 劫持。
- 内存保护：NX、ASLR、PIE、Canary、RELRO、CFG、CET。

### 安全中的用途

| 概念 | 安全场景 |
|---|---|
| ELF/PE | 恶意样本分析、加壳、隐藏导入 |
| PLT/GOT | GOT 覆写、延迟绑定攻击 |
| 调用约定 | 栈溢出、ROP、参数伪造 |
| 动态链接 | DLL 劫持、LD_PRELOAD 提权 |
| 内存保护 | 漏洞利用难度、缓解措施绕过 |
| 加载器 | 持久化、无文件攻击、反射加载 |

### 练习

1. 用 `readelf -h/-S/-s/-r` 分析一个 ELF，解释每个节的作用。
2. 用 `ldd`、`objdump -T` 看动态依赖；用 `LD_DEBUG=libs` 看加载过程。
3. 写一个共享库，用 `LD_PRELOAD` 劫持 `malloc`，观察调用。
4. 用 `checksec` 看一个二进制的保护机制，解释每一项。

### 资源

-《程序员的自我修养》。
-《Linkers and Loaders》（免费在线）。
- CS:APP 第 7 章。

## 十、自测题

1. 解释 `fork()` 后父子进程的地址空间关系；为什么写时复制能提高性能？
2. 线程和进程的区别是什么？什么场景下线程更危险？
3. TCP 为什么需要三次握手，而不是两次？四次挥手最后为什么要等 2MSL？
4. 输入 URL 到页面显示，中间发生了什么？尽可能完整地说一遍。
5. HTTP/2 的多路复用解决了什么问题？它引入了哪些新的安全风险？
6. TLS 1.3 握手比 TLS 1.2 少了哪些往返？为什么安全？
7. 什么是虚拟内存？页表、TLB、缺页中断如何协作？
8. 动态链接的 PLT/GOT 如何工作？为什么会有 GOT 覆写攻击？
9. 数据库的四种隔离级别分别解决什么问题？各自有什么异常？
10. CAP 定理在实际系统中如何取舍？举例说明。
