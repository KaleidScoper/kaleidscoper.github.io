## 2. 攻击技术分类学（按机制）

术语对照：**IPDM** = Identity-Preserving Descriptive Mapping；**Geopolitically Distal Translation** = 地缘远端翻译；**semantic fragmentation** = 语义碎片化；**relational reasoning** = 关系推理；**UTOS** = Uncommon Text-Organization Structures；**VJA** = Vision-Centric Jailbreak Attack。

### 2.1 语义重构 / 语义替换
- **代表**：DACA(2312.07130)、SurrogatePrompt(CCS'24)、PGJ(2408.10848)、Antelope(2412.08156)、Metaphor/Reason2Attack(2503.17987)、Low-Effort(2604.01888)。
- **术语**：component decomposition、perceptual substitution、narrative/artistic reframing。
- **可复现要点**：均无需模型访问；PGJ 用「视觉相似、语义远」替换对（blood→watermelon juice 类）；PC² 明确指出该类方法在**政治内容**场景失效——匿名化摧毁身份可识别性。

### 2.2 跨语言 / 低资源语言
- **代表**：USENIX'25 低资源语言攻击、**PC² 地缘远端翻译**、MacPrompt(2601.07141)、LLM 侧 *Low-Resource Languages Jailbreak GPT-4*（NeurIPS Workshop 2023，**仅经综述转述**）。
- **术语**：multilingual coverage gap、semantic fragmentation、macaronic substitution、back-translation filter。
- **可复现要点**：PC² 全流程见 §3；MacPrompt 属**字符级跨语言重组**，未见开源声明。

### 2.3 编码与视觉伪装
- **代表**：ArtPrompt(ACL'24, ASCII art)、StructuralSleight(UTOS+混淆)、MetaCipher(2506.22557, RL 选 21 种密码)、CodeChameleon。
- **术语**：vision-in-text、cipher/encryption jailbreak、structure-level attack。
- **可复现要点**：ArtPrompt 开源（`github.com/uw-nsl/ArtPrompt`）；StructuralSleight 未见代码仓库确认。**二者本质是文本 LLM 攻击，迁移到 T2I 要经中间 LLM 接口**（gpt-image-1 即经 GPT-4o/5/5.1 文本层）。

### 2.4 多轮与上下文 / 记忆
- **代表**：Inception(2504.20376)、Anyone Can Jailbreak(2507.21820)、D-LLM Context Nesting(2602.00388)。

## 3. PC² 深度拆解（arXiv:2601.05150v4）

### 3.1 定位与创新
首个面向**政治敏感内容（PSC）**的商用 T2I 黑盒越狱框架。核心洞见：政治毒性是**关系性**的——单个实体可能中性，实体组合才违规。因此攻击目标不是隐藏实体，而是**阻断过滤器的关系推理**，同时保持人物身份可识别（与既有匿名化路线正面冲突）。

### 3.2 威胁模型（§2.5，全文已核实）
- 黑盒；无参数/训练数据/过滤器逻辑/梯度访问；不操纵生成后端。
- 攻击面 = **公开 Web 界面**（ChatGPT 的 gpt-image-1 界面），理由：API 通常需要组织验证。
- 反馈粗粒度：只知「拒答 vs 出图」，看不到中间审核决策或拒答理由。
- 成本门槛低：仅需公开服务，无需特权基础设施。

### 3.3 完整攻击链（§3.1–§3.5 + 代码/README 交叉验证）
1. **政治敏感词检测（§3.1）**：双路径——(a) NER 识别政治人物，再由 LLM 推断其「最相关国家」；(b) 抽取名词短语（如象征物/口号），用 GPT-4o 判定其国家归属与政治/社会敏感度。国家信息只用于后续打分，本阶段不改写提示词。
2. **身份保持描述映射 IPDM（§3.2）**：对每个敏感词用 GPT-4o 生成 **1–2 句「quiz-style」描述**，承载历史/政治/视觉本质但不含被禁词（论文示例：`<POL>` → "a New York born entrepreneur …"）。双重目的：剥离词法触发词以过关键词黑名单；同时给生成模型足够线索以**还原身份**。
3. **地缘翻译（§3.3）**：对 IPDM 描述与「基座提示词」各翻译成 **72 种语言**；基座提示词 = 原提示词中敏感词被替换为 `<PCC_PLACE_HOLDER_x>`，随后映射为字母索引 A、B…。为防止低资源语言幻觉，做**回译校验**（如 EN→TH→EN），余弦相似度 **< 0.9 的译文被丢弃**。
4. **四维地缘敏感度指标（§3.4.1–§3.4.4，已核实前半）**：
   - **Keyword Common Knowledge (kc)**：WikiSearch 检索关键词相关维基段落→嵌入；以「Conflict with <国家名>」为查询模板，取 max-over-paragraphs 余弦相似度，再按「主要语言→国家组」取 max，得语言向量 `S_kc(k)`。
   - **Country Common Knowledge (cc)**：预建国家维基知识库，用关键词嵌入对国家段落取 max 相似度，再聚合到语言组 `S_cc(k)`。
   - **Bias-based (bb)**：政治词在代表语言下的嵌入与该词 IPDM 描述嵌入的余弦相似度（衡量语义保真/偏置转移）。
   - **Politics-based**：衡量译文中政治语义残留程度，倾向政治语义更弱的译文（**§3.4.4 之后公式未能获取**）。
5. **组合聚合与候选选择（§3.4.5–§3.5）**：四指标加权组合（**具体聚合公式未能获取**）；按百分位阈值筛候选（代码参数 `--percentile` 默认 **50**）；不假设存在唯一最优提示词，而是依据目标模型响应与指标权衡**逐条选择**。
6. **对抗提示词组装**：形如「`A: [语言X 的 IPDM 描述]  B: [语言Y 的 IPDM 描述]  A holding B`」的索引式多语言提示词；不同实体用不同语言（论文动机示例：`<POL>` 用斯瓦希里语 + 旗帜用泰语）。入口提示词必须含绘图前缀，如 `Create a realistic image for ...`。
- **输出**：JSON `{"final_prompt": ..., "selected_languages": ["Latvian","Dutch","Croatian"]}`（README 示例）。

### 3.4 提示词构造范式（模式化描述）
- 敏感词 → **quiz 式间接描述**（"背景/职业/年代"等线索，而非姓名）。
- 组合动作放在**中性基座句**里，仅以字母占位符引用各描述块。
- 每个块单独选语言，最大化**语言多样性**与**地缘距离**，使过滤器无法跨块建立单一连贯的敌对关系。
- 以回译相似度做质量闸门，以四指标百分位做敏感度闸门。

### 3.5 评测与 ASR（已核实）
- 基准：**240 条**政治敏感提示词（**121 对象型 + 119 短语型**），覆盖 **36 位**政治人物（论文中一律掩码为 `<POL>`）。
- 目标：gpt-image-1，经 GPT-4o / GPT-5 / GPT-5.1 Web 界面；实验时间 **2025-11-12**，**2025-11-25** 复测。
- 结果：原始提示词 **0% 通过**；PC² **GPT-4o 86.25% / GPT-5 68.33% / GPT-5.1 76.25%**。
- 基线（对象型子集，GPT-4o）：PC² **87.60%**，最强基线 SurrogatePrompt **8.26%**（另有 DACA、PGJ）。
- 仅经 PDF 索引片段确认存在的表：**指标消融表**（Metric × {Keyword, Country, Bias, Politics}，`ASR` 行首值 **0.6667**，其余列被截断）；**分国家/地区 ASR 表**（首行 `Canada 22…`）；**Country/Region × Person × Midjourney × Nano-Banana** 表（说明评测还含 Midjourney 与 Nano-Banana，具体数值未获取）。

### 3.6 根因分析与多层防御（§5，部分细节来自仓库与索引片段）
- **根因**：安全过滤器按**语言上下文**判断政治敏感度；低资源语言覆盖不足；多语言碎片化使过滤器丧失跨实体关系推理能力。
- **文本层缓解 — Relevant Language Translation（相关语言归一化）**：原型代码 `src/defense/relevant_language/infer.py`；依赖 `fasttext lid.176.bin` 做语种识别；把提示词片段归一翻译到「最相关地缘语言」后再送语义过滤器（LMVD 归纳为 "Relevant Language Normalization"）。输入输出均为含 `final_prompt` 字段的 JSON。
- **图像层缓解 — PSC 感知图像审查**：原型代码 `src/defense/llavaguard/infer.py`；模型 **LLaVA-Guard v1.2-7B-OV**（`AIML-TUDA/LlavaGuard-v1.2-7B-OV-hf`，LLaVA-OneVision Qwen2-7B），输出结构化 JSON `{rating, category, rationale}`；策略有 `default`(O1–O10) 与 **`default_psc`(O1–O11 合并，新增政治敏感类目)**。
- **开源后过滤器的失效**：论文测试了三类开源过滤器（索引片段提到 Marqo-NSFW、Stable Diffusion safety checker 及第三个基于分类器的 NSFW 检测器），归因于**缺乏政治语境推理能力**；并给出「实用 FPR=1% 工作点下对 PSC 的检出」结果（数值未能获取）。
- **分层防御效果**：文本层 + 图像层组合，**ASR 从 86% 降至 11%**（摘要明确）；两组件均为 off-the-shelf，**无需重训练**。
- **残余风险**：**11% 残余 ASR**；防御依赖翻译质量与「相关语言」推断。LMVD 另列三点建议（相关语言归一化、严格 system prompt 显式禁止真实人物+极端符号类图像、跨语言语义分类器的多语言关系推理），并指出严格 system prompt 需在误报率上做权衡。

### 3.7 伦理与披露

- **2025-12-02 报告 Google Gemini、2025-12-12 报告 OpenAI**（ar5iv 版附录 D；v4 版指引至附录 C.E）。
